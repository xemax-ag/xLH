# xLH

Detailed description of the xLH products: <a href="https://xlh.xemax.ch" target="_blank">xlh.xemax.ch</a>

## Description
xLH products are characterized by a clear didactic focus in an industry-oriented environment.
Industrial workflows are made affordable and adapted to an individualized learning level for **EVERY** learner.

Features
- competence-oriented (hands-on) learning with real setups
- learning should be enjoyable, encouraging intrinsic motivation
- work with industrial tools and industry-oriented workflows
- independent of time and location
- product portfolio optimized for didactic requirements
- the learning workstation at home becomes a lab (high mobility)
- toolchain and work processes from industry
- open concept that allows custom extensions (projects)
- can be used across subjects and topics (harmonized toolchain)
- system architecture follows common modern industrial implementations
